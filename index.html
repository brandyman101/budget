Settings & backup

Export regularly as a backup. Your data lives in this browser's storage only.

With a passphrase set, your data is encrypted on this device before it syncs — the server only ever holds scrambled text. Use the same passphrase on every device. If you forget it, the synced copy can't be read back.

Sync is off. Set a Worker URL and secret to sync between devices.

Sync sends your data to your own Worker with the secret in an Authorization header. Without the secret the Worker refuses the request.
